### 1. 헤더 컴포넌트 개선 (header_seo.tsx)

#### 파일 위치
```
/src/components/header_seo.tsx
```

#### 주요 변경사항

##### 1.1 로고 중앙 정렬
- NOI.LAB 로고와 팀 이름을 헤더 중앙에 배치
- 레이아웃을 `justify-between`에서 `justify-center`로 변경
- 메뉴 버튼을 절대 위치(`absolute right-0`)로 이동

##### 1.2 검색창 추가
- 헤더 왼쪽에 검색창 구현
- 검색 아이콘(Search) 포함
- 플레이스홀더: "Search problems..."
- 너비: 256px (w-64)
- 포커스 시 인디고 링 효과

##### 1.3 후원 버튼 추가
- 헤더 오른쪽에 "Donate" 버튼 추가
- 핑크-로즈 그라디언트 디자인
- 하트 아이콘(Heart) 포함
- 호버 시 그림자 효과 및 색상 변화

##### 1.4 레이아웃 구조
```
[검색창]    [로고 + NOI.LAB]    [Donate 버튼] [메뉴]
```

#### 사용된 아이콘
- `Search` - 검색 기능
- `Heart` - 후원 버튼
- `Menu / X` - 메뉴 토글
- `Home, Settings, HelpCircle, LogOut` - 드롭다운 메뉴
