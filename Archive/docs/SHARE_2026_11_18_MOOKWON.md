## 4. 리뷰 화면 사용법

- Mookwon 님 계정은 **관리자(admin)**로 지정했습니다. 관리자는 리뷰도 할 수 있습니다.

- 판정 종류는 4가지입니다. 코멘트는 승인 외에는 필수입니다.

| 판정 | 의미 |
|---|---|
| Approve | 승인 (필요 승인 수: 지금은 모든 문제 1명) |
| Request changes | 수정 요청 |
| Reject | 반려 (학생에게 숨김) |

- 실수한 판정은 **Withdraw my decision**으로 철회할 수 있습니다. 철회 기록도 남습니다.
- 자동 검사에 실패한 문제는 확인 체크와 코멘트를 남겨야 승인할 수 있습니다.

  - v0.1 사다리: 관리자 편집 화면 + markdown 원본도 같이 수정
  - 출처 없는 문제: 관리자 편집 화면
  - 고친 뒤에는 `report.py --save`로 재검사
- 리뷰 기록은 지우거나 고칠 수 없고 영구 보관됩니다.

**리뷰 화면 추가 기능**
- `/admin/reviews` 위쪽에 두 자동 검사(정규, AI)의 On/Off와 마지막 실행이 보이고, 관리자는 **Turn off / Turn on**으로 켜고 끌 수 있습니다. 끄면 밤 실행과 직접 실행이 모두 멈춥니다.
- **Automatic check history**(`/admin/reviews/history`): GitHub 실행 기록(밤 실행·직접 실행, 결과)과 실행마다 저장된 결과(문제 수, 단계별 통과·경고·실패, 경고가 난 문제 목록)를 볼 수 있습니다.
- AI 검사는 이제 실행 한 번에 코드 실행 환경을 하나만 써서 비용이 크게 줄었습니다.
