## 4. One answer form and a LaTeX guide

The "Written solution" and "Short answer" tabs became one form:

- **Explanation (LaTeX)** with a preview, and an **Answer** box, with one **Submit** button.
- Answer filled in → the number is checked right away (free, no AI) and XP is given as before. The explanation is
  **saved with the submission but not graded** (decision today).
- Answer left empty → the explanation goes to AI grading, as before. This is for proof problems with no number answer.
- **"How to write LaTeX"** under the editor: a table (what you type → what you get) for fractions, powers, subscripts,
  roots, floor, inequalities, sets and matrices, and an **Insert example** button.
- The answer box also accepts LaTeX fractions (`\frac{3}{8}`, `\dfrac{3}{8}`); `\floor{x}` and `\ceil{x}` now render.

How to write a matrix (in the explanation, not the answer box):

```latex
$$
A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}
$$
```

## 5. Saved work and progress tracking

Goal: a problem solved once should not have to be solved again, and the site should show what you are working on.

- **Solved problems** open to a green "Solved" box: your answer, your explanation (rendered), the date first solved,
  the number of submissions, and **Solve again**.
- **Unsent work is kept** while you type (in this browser, per account). Coming back shows "Your unsent work on this
  problem was restored" with **Start over**. After a wrong answer, the last attempt is loaded instead.
- **Problems list:** each problem shows **Solved** or **In progress** (opened or tried, not solved).
- **Learning path:** solved steps have a check mark.
- Opening a problem now counts as starting it, so Home's activity sees it.
- New: `/api/user/submissions` (your own submissions to one problem, read-only).

## 6. Data incident and cleanup

- **What happened:** lists build one problem window per row in the background. The first version of §5 loaded data
  in all of them, so opening the Problems page marked **231 problems as "started"** on Mookwon's account
  (18:00–18:01 UTC). A database trigger also added 1 to "Attempted by" on each of those problems.
- **Fix:** the problem window now loads nothing until it is opened. Loading the Problems page went from about
  1,000 requests to 4 (this also removed old background loading of every problem's text and likes).
- **Cleanup (with Mookwon's OK):** the 231 records were deleted. The trigger lowered "Attempted by" again by itself
  (tested on one record first). The 12 real earlier records and all submissions are unchanged.
- Found along the way: the database keeps `problems.starts_count` in step with `user_starts` (+1 on insert,
  −1 on delete). This trigger is not in the repository's SQL files.
