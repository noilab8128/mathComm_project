## 5. New tools (in `olympiad/ladders/`)

| Tool | What it does |
|---|---|
| `patch_live_text.py OLD.md NEW.md --only P3 [--apply]` | Updates live problem text, solution text and analysis of a ladder, only where the live row still equals the old markdown; anything edited on the site is skipped and reported. Refuses answer changes |
| `lint_ladders.py <files>` | Wording checks before upload. Errors: a step pointing to another step, raw LaTeX outside `$…$`, "It is known that", no example hint. Warnings: "the same triangle" (is it in the Setup?), a step's answer appearing in the Setup. On the files from before today it finds the Cutting Colours, Zero Sums, Switching Lamps, Halfway Point and Square Triples problems |
| `v2/verify_hint_examples.py` | Recomputes every number in the example hints |
| `import_guides_hints.py --hints-only` | Writes only hints (without it, the script also rewrites analysis, flow and Challenge solutions). Reads `- Example:` lines |

## 6. Procedure for the next problems

1. Write the ladder. Each step must make sense with only the Setup above it. Give the reason with every fact. The Setup
   example must not be a step's answer. Use one word for one meaning, say whether 0 and repeats are allowed, and write
   math in Unicode.
2. Add one `- Example:` hint per ladder (other numbers than the steps) and the direction hints.
3. Run `verify_v2_batchN.py`, `verify_hint_examples.py` and `lint_ladders.py` (0 errors). Read the warnings. Read every
   step once as a student would.
4. Upload new ladders only: `import_ladders_v2.py <file> --only <new keys> --apply`. Then hints:
   `import_guides_hints.py <all hint files> --hints-only --apply`.
5. The next day, check Osang's nightly results on `/admin/reviews` and fix any warnings.
6. To fix a live problem: copy the markdown first, edit, check, then `patch_live_text.py`. To delete: count what refers
   to it, back it up, then delete.
