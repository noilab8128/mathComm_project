## 5. Skill Tree redesign

Goal (from the team): show the student **where they are**, both the ladder they are on and their place on the map
of math topics, in a way that is easy to read. Rules: `docs/SKILL_TREE_RULES.md` (sections 2.3, 4.6, 6, 7).

### 5.1 The skill map: 16 core topics

The 70 level-3 categories were too many to show. The Skill Tree now uses its own 3-level map
(`src/lib/skillMap.ts`): **4 fields › 2 areas each › 2 core topics each**. Each core topic gathers existing
categories, so the database and problem tags did not change.

| Field | Areas and core topics |
|---|---|
| Algebra | Equations and Inequalities (Inequalities and Optimization, Polynomials and Factoring) · Functions and Sequences (Sequences, Sums and Floors, Functional Equations) |
| Number Theory | Divisibility (Primes and Divisors, Congruences) · Equations and Digits (Diophantine Equations, Digits and Bases) |
| Combinatorics | Counting (Counting and Probability, Graphs) · Combinatorial Reasoning (Invariants and Games, Extremal and Pigeonhole) |
| Geometry | Triangles and Circles (Triangle Centres and Circles, Congruence and Similarity) · Measurement (Lengths, Areas and Trigonometry, Coordinates and Vectors) |

All 28 ladders fall into 11 of the 16 topics; the other 5 show as "coming soon".

### 5.2 The screen

- **You are here:** the current ladder and step, its map path (e.g. *Number Theory › Divisibility › Primes and
  Divisors*), a step bar, the next badge of that topic with what is missing, and **Continue**.
- **Computer:** tabs for the 4 fields; the open field drawn as a tree (field › 2 areas › 4 topic circles). A circle's
  style shows the state: not started, in progress, badge earned, or "soon". Clicking a circle shows its ladders.
- **Phone:** the same map as a list (field › area › topic, tap to open).
- **My badges:** earned badges and the 3 closest next badges with progress bars.

### 5.3 New badges

| Badge | Rule |
|---|---|
| `<Area>` Navigator | Explorer in 2 core topics of the same area |
| Cartographer | problems solved in 5 different areas |
| Thorough | 3 ladders finished with every step solved |
| First Try / Sharpshooter | 1 / 5 Challenges correct on the first attempt |
| Persistent / Unstoppable | 1 / 5 problems solved after 3 or more wrong attempts |

- First Try and Persistent use the attempt record; `/api/user/first-solves` now also returns, for each solved
  problem, the wrong attempts before the first correct one (the signed-in user's own record only).
- Not built yet: a "no hints" badge (hint use is not recorded) and streak badges (the streak never updates).
